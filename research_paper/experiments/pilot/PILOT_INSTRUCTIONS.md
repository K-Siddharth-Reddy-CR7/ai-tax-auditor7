# 10-item pilot: instructions for reviewers

**Purpose.** All benchmark labels are produced automatically from reference data (HS 2022, ISO 3166-1, CLDR 47) or from pre-declared rules. The pilot checks whether a human reading the same evidence agrees with those labelling rules. It does **not** produce new labels. Labels were generated by code written with AI assistance, so they are *rule-derived*, not independently verified, until humans check a sample.

**Who.** Two reviewers, independently. Proposed: Author 1 (Syeda Sayeeda Farhath) and Author 4 (Baalne Anjali), because the student authors are unavailable. Any two authors may do it. Reviewers must not discuss items before both have finished.

**Time.** About 1–2 minutes per item, so roughly **15–20 minutes per reviewer**. Record your minutes in the sheet.

**What to judge, for each item:**
1. **Products.** Given only the input text, should an assistive tool that knows the catalogue's 60 product types (`pilot/catalogue_base_types.csv`) answer with the stated HS-6 code, or decline? The reference description is shown for context.
2. **Countries.** Does the input clearly identify the stated country? If so, should the tool compute (the country is in the 40-country tax table) or refuse (no tax data)? For ambiguous strings, should it refuse to identify?
3. Mark `agree`, `disagree` or `unsure`. If you disagree, write the outcome you think is correct and one line on why.

**Do not judge** whether a tax rate is legally correct, or whether the catalogue's own HS assignment is legally correct. The paper reports those as separate limitations.

**After the pilot.** If both reviewers agree with ≥ 9 of 10 items and no labelling *rule* is shown to be wrong, the authors approve freezing (`run_all.py --stage freeze --approved-by NAME`). If a rule is wrong, it is corrected, the draft is rebuilt and the change is logged before freezing.

**Optional label-quality audit (recommended, after the pilot).** One reviewer checks a stratified random sample of 60 test items, 6 per stratum (≈ 45–60 min). The result gives a label-error estimate with a 95 % Wilson interval for the paper. If skipped, the paper must state that labels were only pilot-checked.
